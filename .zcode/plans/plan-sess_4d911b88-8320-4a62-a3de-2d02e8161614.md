## 优化 PluginCard.vue（仅官方插件）

只修改 `frontend/src/pages/profile/components/PluginCard.vue` 一个文件。

### 改动点

**1. 官方插件不显示来源 tag**（当前第 9 行）

```html
<t-tag size="small" variant="outline">{{ sourceLabel }}</t-tag>
```
→ 增加 `v-if="!item.official"`，官方插件不再显示「npm / github / local」来源；官方/第三方标签（第 6-8 行）保留不变。

**2. 官方插件 rowsLabel 单行省略 + tooltip**（当前第 16 行）

模板改为：官方插件且有 rows 时，用 `t-tooltip`（`content` 传完整 `rowsLabel`，默认 `placement="top"`）包裹一个可截断的 span；第三方插件保持原样渲染。

```html
<div class="plugin-rows">
  <t-tooltip v-if="item.official && rowsLabel" :content="rowsLabel" placement="top">
    <span class="plugin-rows--truncate">{{ rowsLabel }}</span>
  </t-tooltip>
  <template v-else>{{ rowsLabel }}</template>
</div>
```

样式新增（只作用于官方分支的 `.plugin-rows--truncate`）：

```less
.plugin-rows--truncate {
  display: block;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
```

卡片容器 `.plugin-info` 已有 `min-width: 0`，单行省略可正常生效；官方插件 rows 多时卡片不再被撑高，hover 显示完整行 id 列表。

### 不做的事

- 不改第三方插件的 rowsLabel 展示（维持多行/现状）。
- 不删「官方/第三方」标签、不改数据模型、不改其他文件。
- 纯样式微调 + 一行条件渲染，按 AGENTS.md 豁免 docs 同步。
