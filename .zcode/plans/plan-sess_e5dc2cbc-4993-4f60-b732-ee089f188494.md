## 目标

纯净模式开启/关闭与插件启用/禁用保持一致：web 服务运行时提示需要重启才生效，询问是否立即重启。

## 改动清单

### 1. `frontend/src/pages/profile/index.vue`

**`onPureMode`（当前 189-192 行）** 改为：
```ts
async function onPureMode(on: boolean | string | number) {
  const enabled = !!on
  await store.setPureMode(enabled)
  const status = store.server.status
  if (status === 'stopped' || status === 'unknown') {
    // 服务未运行：无需重启，直接反馈状态
    MessageUtil.success(enabled ? t('toolbar.pureOn') : t('toolbar.pureOff'))
    return
  }
  await promptRestart(enabled ? 'pure-on' : 'pure-off')
}
```

**`promptRestart`（当前 243-278 行）**：
- action 类型扩展为 `'enabled' | 'disabled' | 'removed' | 'pure-on' | 'pure-off'`（提取 `type RestartAction`）
- `actionKey` 映射新增 `'pure-on': 'restart.actionPureOn'`、`'pure-off': 'restart.actionPureOff'`
- 确认文案：纯净模式（`pure-on`/`pure-off`）使用无插件名的 `restart.confirmPure` 模板；其余保持现有 `restart.confirm` 模板（含 `{name}`）

### 2. `frontend/src/i18n/zh.ts` 与 `en.ts`

新增（restart 段）：
- `restart.actionPureOn`: 「开启纯净模式」/ "Pure mode on"
- `restart.actionPureOff`: 「关闭纯净模式」/ "Pure mode off"
- `restart.confirmPure`: 「已{action}，改动需重启 dsh web 服务后生效，是否立即重启？」/ "{action}. The change takes effect after restarting the dsh web server. Restart now?"

更新：
- `settings.confirmRestartHint`: 「启用 / 禁用 / 卸载插件或切换纯净模式后，若 web 服务在运行则询问是否立即重启」（en 同步）

### 3. `docs/01-plugin-manager.md`

第 109 行「插件变更后的重启提示」补充：纯净模式开启 / 关闭同样触发重启询问（若 web 服务在运行）。

## 行为结果

- 服务未运行（stopped/unknown）：显示原 success toast（纯净模式状态已变更，下次启动生效）
- 服务运行中：弹 DialogPlugin 确认框「已开启/关闭纯净模式，改动需重启 dsh web 服务后生效，是否立即重启？」→ 立即重启 / 稍后（toast 提示下次生效）
- 外部启动的服务：toast 提示手动重启
- 设置中关闭 `confirmRestart`：静默跳过（与插件开关行为一致）
