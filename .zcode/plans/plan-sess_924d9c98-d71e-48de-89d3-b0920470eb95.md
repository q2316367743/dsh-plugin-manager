# 新增系统托盘（任务栏）功能

## 目标
应用启动后常驻系统托盘，菜单含三项：**显示/隐藏**、**启动/停止服务**、**退出**。左键单击托盘图标弹出菜单（macOS 菜单栏标准行为）。

## 架构决策
- **托盘在 Go 侧实现**（`app.SystemTray.New()` + `application.NewMenu()`），"显示/隐藏"、"退出"纯 Go 原生处理。
- **"启动/停止服务"经事件路由到前端**：复用现有 Pinia store（`serverStart`/`serverStop`/`refreshServerStatus`，含 KV pid 跟踪、busy 互斥、端口轮询、残留进程清理）。Go 侧重写会重复整套逻辑。
- 前端把服务状态变化回推 Go，动态切换菜单项标签（"启动服务" ↔ "停止服务"）并控制禁用态。

## 事件协议（main.go init() 中 RegisterEvent）
| 事件 | 方向 | 负载 |
|---|---|---|
| `tray:toggle-service` | Go → 前端 | void（无数据） |
| `tray:service-status` | 前端 → Go | `services.TrayServiceStatus{Running bool; Supported bool}` |
| `tray:quit-request` | Go → 前端 | void |
| `tray:quit-ready` | 前端 → Go | void |

## 改动清单

### Go 侧
1. **`services/tray.go`（新建）**：定义 `TrayServiceStatus` 事件负载类型。
2. **`tray.go`（根目录新建，`setupTray(app, win)`）**：
   - `tray := app.SystemTray.New()`，`SetIcon`（embed `build/appicon.png`）、`SetTooltip`；不设置 OnClick、不 AttachWindow → macOS 左键原生弹出菜单。
   - 菜单：`显示/隐藏`（`win.IsVisible()` → `Hide()` / `Show().Focus()`）；`启动服务` 初始项（点击 → `app.Event.Emit("tray:toggle-service")`，监听 `tray:service-status` 用 `item.SetLabel`/`SetEnabled` 动态更新）；分隔线；`退出`。
   - 退出流程：点击 → `Emit("tray:quit-request")` + 3 秒兜底定时器 `app.Quit()`，并用 `Event.OnMultiple("tray:quit-ready", ..., 1)` 收到前端确认后退出（`sync.Once` 保证只退一次）。
   - **关闭到托盘**：`win.RegisterHook(events.Mac.WindowShouldClose, e.Cancel(); win.Hide())`——钩子先于默认销毁监听执行（源码已验证），用户关窗只隐藏不销毁；程序化 `Close()`/退出走 `Common.WindowClosing` 直发，不受钩子影响，不会卡死退出。
3. **`main.go`（修改）**：init() 注册上述 4 个事件；`win := app.Window.NewWithOptions(...)` 并传给 `setupTray`；`Mac.ApplicationShouldTerminateAfterLastWindowClosed` 改为 `false`（关闭窗口后应用继续后台运行）。

### 前端侧
4. **`frontend/src/hooks/UseTray.ts`（新建）**，App.vue setup 中调用 `useTray()`，集中托盘桥接：
   - `watch([() => store.server.status, () => store.hasWebApp])` → `Events.Emit('tray:service-status', { running, supported })`（running = running-own 或 running-foreign；supported = hasWebApp，无 web 应用时菜单项禁用）。
   - `Events.On('tray:toggle-service')` → 按当前 status 调 `store.serverStart()` / `serverStop()`（store 内已有 busy/dsh 守护，前端未就绪时安全 no-op）。
   - `Events.On('tray:quit-request')` → `await store.serverStop()` 后 `Events.Emit('tray:quit-ready')`。
5. **`frontend/src/App.vue`（修改）**：引入并调用 `useTray()`。

### 绑定 / 文档 / 验证
6. 执行 `wails3 generate bindings`（~/go/bin/wails3 已装）刷新事件绑定；`go vet ./...` 验证 Go 侧。
7. `npm run check`（vue-tsc）前端 typecheck，不 build（RL-07）。
8. 更新 `docs/01-plugin-manager.md`（新增托盘功能章节：事件协议、关键文件、关闭到托盘注意事项）并同步 `docs/README.md` 索引描述（RL-06）。

## 注意事项
- 托盘图标用 `build/appicon.png`（彩色），macOS 菜单栏后续可换 `SetTemplateIcon` 模板图精修。
- 服务是 detached 进程，"退出"经前端 `serverStop` 停服务后应用才退出；前端无响应时 3 秒兜底强制退出。
- 本机 macOS 为主目标，关闭到托盘钩子注册 `events.Mac.WindowShouldClose`（其他平台常量存在但不触发，无副作用）。
